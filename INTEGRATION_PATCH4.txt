============================================================
PATCH SET 4 — BCE-with-logits fix (autocast-safe)
============================================================

This patch fixes the autocast error you hit during bf16 training:

    RuntimeError: torch.nn.functional.binary_cross_entropy and
    torch.nn.BCELoss are unsafe to autocast.

The fix changes the mask head to output LOGITS (no sigmoid), and
the residual loss to use binary_cross_entropy_with_logits which
IS autocast-safe.

------------------------------------------------------------
WHY THIS HAPPENED
------------------------------------------------------------

In Patch Set 1, I had:

  - DynamicMaskHead applied nn.Sigmoid() at the end
  - DynamicResidualLoss used F.binary_cross_entropy(mask, pseudo)

This worked fine in:
  - The single-batch smoke test (which used --mixed-precision none)
  - All my CPU verification runs

But it FAILS under bf16/fp16 autocast, because PyTorch explicitly
disables binary_cross_entropy under autocast. The error message
even says:

    "combine the two layers using
     torch.nn.functional.binary_cross_entropy_with_logits
     or torch.nn.BCEWithLogitsLoss. binary_cross_entropy_with_logits
     and BCEWithLogits are safe to autocast."

You hit this when running:
    python train.py --overfit --batch-size 2 --image-scale 1.0 --mixed-precision bf16

------------------------------------------------------------
THE FIX
------------------------------------------------------------

Two file changes:

1. src/models/world_model/mask_head.py
   - Removed nn.Sigmoid() from the Sequential
   - The head now outputs RAW LOGITS
   - Added docstring explaining why

2. src/losses/dynamic_residual_loss.py
   - Changed F.binary_cross_entropy -> F.binary_cross_entropy_with_logits
   - Removed the clamp_mask logic (no longer needed — BCE-with-logits
     is numerically stable for any logit value)
   - Added mask_probs = sigmoid(mask).detach() in the return dict,
     for visualization and metrics

Plus the consumers needed updates to apply sigmoid when they
need probabilities (since outputs["mask"] is now logits):

3. trainer.py
   - In _evaluate_on_loader: torch.sigmoid(outputs["mask"]) before
     passing to SegmentationMetrics
   - In _log_mask_visualization: uses loss_output["mask_probs"]
     (already sigmoid'd by DynamicResidualLoss) for image logging

4. src/utils/metrics.py
   - SegmentationMetrics.update now auto-detects logits (if max>5
     or min<-5, applies sigmoid internally) for robustness
   - This means you can pass either logits OR probabilities; both work

5. src/models/world_model/model.py
   - Added "mask_probs": None placeholder in output dict (gets
     populated by TotalLoss with sigmoid(logits) for convenience)

------------------------------------------------------------
HOW TO APPLY
------------------------------------------------------------

From your repo root:

    cd ~/git/EventCameraProject
    unzip /path/to/all_patches_with_bce_fix.zip

This OVERWRITES the files listed above. If you've made local
modifications to any of these files, back them up first.

Then run:

    # 1) Single-batch smoke test (verifies everything works)
    python test_trainer_one_batch.py \
        --dataset-root ~/HDD/EventDatasets/EVIMO2_official/ \
        --image-scale 0.5 --mixed-precision bf16

    # 2) Overfit test on single sequence
    python train.py \
        --overfit \
        --dataset-root ~/HDD/EventDatasets/EVIMO2_official/ \
        --batch-size 2 --image-scale 1.0 --epochs 20 \
        --mixed-precision bf16 --viz-every-n-steps 50

The autocast error should be GONE.
